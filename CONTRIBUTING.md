# Contributing to BatteryBar

Thanks for helping improve BatteryBar. Please search existing issues before opening a new one.

For bug reports, include your Windows version, battery model or driver if relevant, expected and actual behavior, and clear reproduction steps. Remove personal information from screenshots and logs.

For code changes, keep the app compatible with the .NET Framework compiler used by `build.ps1`. Run `./build.ps1` and `./tests/Verify.ps1` in Windows PowerShell before opening a pull request. Explain user visible changes and attach a screenshot for UI changes.

Please keep discussions respectful and focused on the project.
